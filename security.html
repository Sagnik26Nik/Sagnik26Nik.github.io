Security Feature 01

HTTPS / TLS Encryption

✅ Active

GitHub Pages automatically provisions TLS certificates via Let's Encrypt for all *.github.io domains. All HTTP traffic is permanently redirected to HTTPS (HTTP 301). TLS 1.3 encrypts data between browser and server, preventing eavesdropping and man-in-the-middle attacks.

Terminal — verify TLS
# Check TLS and HSTS header
curl -I https://sagnik26nik.github.io

# Expected response includes:
# strict-transport-security: max-age=31536000
# x-content-type-options: nosniff

# View certificate chain
openssl s_client -connect sagnik26nik.github.io:443 -showcerts 2>/dev/null | head -30
How it works: Browser sends ClientHello → Server sends certificate → Browser verifies certificate against trusted CA (Let's Encrypt) → TLS handshake → All subsequent traffic is encrypted with AES-256-GCM.
Security Feature 02

XSS Prevention + Content Security Policy

✅ Active

Two-layer defense: a strict Content Security Policy (CSP) header blocks script injection from untrusted origins. DOMPurify (loaded from Cloudflare CDN) sanitizes all user-supplied HTML before it ever touches the DOM.

js/security.js — sanitize function
// Every user input goes through this before rendering
function sanitizeInput(userInput) {
  return DOMPurify.sanitize(userInput, {
    ALLOWED_TAGS: ['b', 'i', 'em', 'strong', 'p'],
    ALLOWED_ATTR: []   // no attributes allowed at all
  });
}

// Example:
sanitizeInput('Hello <script>alert("xss")</script> World');
// → "Hello  World"  ✅ script tag stripped

Security Feature 03

Brute-Force Protection — Rate Limiting

✅ Active

Client-side token bucket limits form submissions to 5 attempts per 60 seconds per session. After the limit is hit, the form locks and shows a countdown. In a Node.js backend this pairs with express-rate-limit.

js/security.js — RateLimiter class
class RateLimiter {
  constructor(max = 5, windowMs = 60000) {
    this.max = max;
    this.windowMs = windowMs;
    this.attempts = 0;
    this.resetAt = null;
  }

  check() {
    const now = Date.now();
    if (this.resetAt && now > this.resetAt) {
      this.attempts = 0;      // window expired, reset
      this.resetAt = null;
    }
    if (this.attempts >= this.max) {
      const wait = Math.ceil((this.resetAt - now) / 1000);
      throw new Error(`Rate limit hit. Try again in ${wait}s.`);
    }
    this.attempts++;
    if (this.attempts === 1) this.resetAt = now + this.windowMs;
  }
}

Security Feature 04

CSRF Token Protection

✅ Active

Every page generates a unique CSRF token using crypto.randomUUID() and stores it in sessionStorage. The token is injected as a hidden field into every form. On submission, the token is validated before any data is processed. Cross-site requests won't have the token and will be rejected.

js/main.js — CSRF injection (runs on every page load)
function injectCSRFTokens() {
  // Get or create token for this session
  let token = sessionStorage.getItem('csrf_token');
  if (!token) {
    token = crypto.randomUUID();
    sessionStorage.setItem('csrf_token', token);
  }

  // Inject into every form on the page
  document.querySelectorAll('form').forEach(form => {
    let input = form.querySelector('[name="_csrf"]');
    if (!input) {
      input = document.createElement('input');
      input.type = 'hidden';
      input.name = '_csrf';
      form.appendChild(input);
    }
    input.value = token;
  });
}

Security Feature 05

Secure Cookies & Session Flags

✅ Active

Session cookies are configured with three critical security flags: HttpOnly prevents JavaScript from reading the cookie (blocks XSS-based theft), Secure ensures the cookie is only sent over HTTPS, and SameSite=Strict blocks cross-site request forgery.

Server — secure cookie configuration (Python/Flask example)
# Python / Flask backend cookie setting
from flask import make_response

response = make_response(redirect('/dashboard'))
response.set_cookie(
    'session_id',
    value=generate_session_token(),
    httponly=True,          # JS cannot read this cookie
    secure=True,            # HTTPS only
    samesite='Strict',      # No cross-site sending
    max_age=3600,           # Expires in 1 hour
    path='/'
)

# Resulting Set-Cookie header:
# Set-Cookie: session_id=abc123;
#   HttpOnly; Secure; SameSite=Strict;
#   Path=/; Max-Age=3600
