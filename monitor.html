📊 Google Analytics

✅ Active on all pages

Google Analytics tracks pageviews, session duration, referrer sources, and device types. IP anonymization is enabled (anonymize_ip: true). The tracking script is loaded asynchronously — it never blocks page rendering.

📡 Prometheus-style Metrics

In production, a /metrics endpoint exports these counters and histograms. Prometheus scrapes every 15s; Grafana visualizes them.

/metrics — Prometheus exposition format
# HELP http_requests_total Total HTTP requests received
# TYPE http_requests_total counter
http_requests_total{method="GET",status="200"} 1247
http_requests_total{method="POST",status="200"} 89
http_requests_total{method="POST",status="429"} 12
http_requests_total{method="GET",status="404"} 34

# TYPE response_latency_seconds histogram
