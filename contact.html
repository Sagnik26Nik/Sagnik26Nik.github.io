Contact Form

Demonstrates Firebase Firestore + full security pipeline: CSRF → validation → DOMPurify → rate limiting → database.

🔒 HTTPS 🛡️ CSRF Token 🧹 XSS Sanitized ⏱️ Rate Limited (3/5min) 🔥 Firebase Firestore
0/2000

Inputs are sanitized with DOMPurify before storage. Rate limit: 3 submissions per 5 minutes.

Security Pipeline

  1. CSRF Validation

    Token generated on page load via crypto.randomUUID(). Validated against sessionStorage before any processing.

  2. Client Validation

    Required fields, length limits, email format — checked before any data leaves the browser.

  3. XSS Sanitization

    DOMPurify strips all HTML tags and attributes from every field before it touches the database.

  4. Rate Limiting

    Max 3 submissions per 5-minute window. Prevents spam and automated form abuse.

  5. Firebase Firestore

    Sanitized data stored in Firestore with server-side security rules that restrict read access.

⚙️ Setup required:

Replace the Firebase config values in js/contact.js with your own project credentials from the Firebase Console (free tier).
